Requirements — Family Link bypass scripts (Linux)
==================================================

1. adb (Android platform-tools)
   Install:  Debian/Ubuntu: sudo apt install adb
             Fedora:        sudo dnf install android-tools
             Arch:          sudo pacman -S android-tools
   Verify:   adb version

2. Samsung S10 (SM-G973F) connected via USB, with USB debugging enabled
   (Settings > Developer options) and this computer authorized — tick
   "Always allow from this computer" in the phone's RSA prompt.
   Verify:   adb devices    (state must be "device", not "unauthorized")
   If the device isn't detected, install udev rules, e.g.:
             Debian/Ubuntu: sudo apt install android-sdk-platform-tools-common

3. POSIX shell (sh/bash) and gawk/mawk, tr, grep — included with every
   mainstream distribution.

No Python, Node, or other dependencies.
